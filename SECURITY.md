# Security policy

## Supported versions

Security fixes are applied to the latest release and the default branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting feature under the repository **Security** tab.

Include:

- A description of the issue
- Reproduction steps that do not expose third-party systems
- Affected versions or commits
- Potential impact
- Suggested mitigation when known

Never include real credentials, private keys, tokens, internal hostnames, or personal data.

## Security boundaries

ForgeFlow is a reference implementation. Repository owners are responsible for securing runners, branch protection, environment approvals, secrets, SSH trust, target hosts, container registries, and network access.
